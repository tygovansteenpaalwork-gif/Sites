About

Hey! I’m Tygo and I’m a developer from Rotterdam. I’m eighteen and in my third year at the Grafisch Lyceum Rotterdam, a school for design, media and technology. Online I go by ZetFire.

I build tools that make everyday tasks easier. Ember finds backdoors hidden in Roblox free models by reading the model file itself. Jarvis is a voice assistant that listens, talks back and searches the web. I also write Roblox systems in Luau and build websites like this one.

Most of my interest is in security. I read code the way an attacker would write it, then build the tool that catches it.

Every project I make is public, source included, so anyone can check how it works. This portfolio changes as I learn, and the archive keeps every earlier version.

Outside of code: gaming, and finding the next thing I want to understand.
